# v3.1.0 — Protocol V1 stations (FOSSiBOT F7200), read-only

## ✨ Added

**A register profile for protocol V1 devices.** Newer stations such as the
FOSSiBOT F7200 report protocol version 1 in holding register 7 and use a
different register layout, so the V0 table decoded nonsense for them (`AC Input`
showing the PV value, SoC stuck at 0, output states inverted). The integration
now detects the profile from the first settings frame and decodes with
`sydpower/registers_v1.py`, whose indices come from the BrightEMS app bundle
(`portable-power-station-v1`): charge inputs per source, AC output, SoC and
slave SoC, state bits, timers, PV energy counters, firmware versions and the
device clock.

New V1 entities: PV 1-4 Input, AC Grid Power, DC Output Power, PV Energy Today,
Device Clock, Grid Discharging, PV Self-Consumption, Grid Feed Paused,
AI Energy Control. Existing entities keep their names and are filled from the
V1 words.

## ⚠️ Limitations

Writes are not implemented for V1: outputs are bits of input register 75 rather
than holding registers 24-26, so V1 devices get no switches, selects or numbers
until that path is confirmed. V0 devices are unaffected.

## 🧪 Tests

`tests/test_registers_v1.py` decodes two frames captured from an F7200 and
checks them against the values the app showed at the time.
